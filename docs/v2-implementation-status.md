# 家庭記帳 v2：1–7 開發狀態

> 日期：2026-08-13
> 環境：Firebase dev；所有金額與名稱均為示範資料

## 已完成

1. **分類與帳戶**：收入／支出分類、圖示、排序、封存；現金、銀行、信用卡、投資與外幣帳戶；初始餘額、淨資產、帳戶明細與帳務調整。
2. **正式交易**：收入、支出、轉帳、手續費、日期補記、備註、帳戶／分類／專案選擇；所有明細使用同一套整版 UI 編輯或作廢。
3. **預算與專案**：每月／年度分類預算及加總；專案設定、預算、收支與明細，並同時納入整體報表。
4. **定期項目**：週／月／年規則、預設確認、自動入帳、提前顯示、略過、編輯與封存；固定 occurrence ID 防止兩台裝置重複入帳。
5. **代墊與分帳**：我替別人代墊、別人替我代墊、純代墊、自己的份額、多人不同金額、個別剩餘與部分收還款；收還款不重複計入收支。
6. **查看與報表**：首頁真實摘要、預算明細、全部交易、收支行事曆、收入／支出／淨資產趨勢、支出分類與帳戶／專案明細。
7. **同步與防護**：Google 成員登入、Firestore 即時同步、Rules 家庭邊界、文件 revision 衝突檢查、軟刪除／封存，以及手機左緣右滑返回。

## 2026-08-12 記帳與代墊操作修正

- 首頁隱藏金額會同步遮蔽月摘要、預算金額／比例／進度條及交易金額。
- 未結清代墊只以實際剩餘金額判斷，並相容舊資料直接寫在份額內的結清金額；剩餘為 0 不再出現在首頁通知或未結清清單。
- 新增收支預設選取排序第一的分類與帳戶；分類預算餘額改到右側值的下一行，不擠壓分類名稱；金額輸入字級與其他欄位一致。
- 新增記帳底部固定為「儲存／再記一筆」；後者儲存後保留交易類型並重設新表單，同時重新帶入排序第一的預設分類與帳戶。
- 單人代墊只填一次姓名，應還金額由消費總額扣除自己的份額後自動計算；新增第二人後才顯示每人的個別金額欄。
- 餘額調整頁固定使用「帳務調整」分類，因此不再顯示重複的分類欄，儲存移至右上角。
- Firebase dev 已部署並完成 390×844 手機操作驗收；瀏覽器 console 無 error／warning。

## 2026-08-13 排序、報表與明細呈現修正

- 帳戶與分類管理保留拖曳排序，並補上「上移／下移」按鈕；滑鼠、觸控或瀏覽器拖曳支援不完整時仍可精準調整順序。
- 多人代墊的消費總額會由各人應還金額加上自己的份額即時加總；新增、修改、移除對象或切換是否包含自己的消費都會同步更新。
- 記帳整版頂端右側新增「儲存」，下方仍維持左「儲存」、右「再記一筆」，三者沿用同一套驗證與存檔邏輯。
- 統計報表的支出分類可點入完整頁面，依目前選擇的本月、近三個月、今年或自訂區間顯示該分類總額與交易明細。
- 所有共用交易明細改為按日期分組；日期只顯示在分組標題，個別明細不重複標日期，且每筆仍可點入共用記帳 UI 編輯。
- 32 項自動測試、lint 與 production build 通過；Firebase dev 已重新部署。手機與電腦版已驗證新增入口、分類明細、日期分組及排序控制；自動化環境禁止模擬實際滑鼠拖曳，因此拖曳以原生 `draggable`／觸控事件與可實際改序的上下移按鈕共同保障。
- 代墊方向精簡為「我先付／別人先付」；單人代墊移除可由欄位直接理解的自動計算說明，底層計算規則不變。原型來源與瀏覽預覽已同步更新。
- 「我先付／別人先付」兩種代墊方向的主金額欄統一稱為「消費總額」。
- 待確認定期項目保留一鍵確認；點項目內容會開啟完整「確認定期項目」頁，可修改本次日期、金額、分類、帳戶、專案與備註後入帳，且不改動下一期仍使用的規則預設值。
- 交易明細的行事曆／清單切換移至頂端 Bar 右側，以兩個線條圖示呈現；「交易明細」繼續置中，頁面內容不再重複顯示切換列。
- 上述調整通過 32 項測試、lint、production build 並部署 Firebase dev；390×844 手機版已驗證頂端切換與兩種明細模式，console 無錯誤。當下 dev 無待確認資料，因此沒有為畫面測試擅自改動示範定期規則。
