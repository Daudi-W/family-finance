# 家庭記帳第二版 UI 原型

- `family-finance-ui.html`：可直接用瀏覽器開啟的互動預覽。
- `family-finance-ui.source.html`：Codex 對話內嵌視覺化的可編輯來源。

目前內容只使用示意帳戶、姓名與金額，不含正式家庭財務資料。這份原型是正式版的操作與版面規格（golden master），不是僅供靈感參考；正式版會把 Lucide 線條圖示隨前端程式一起打包，不依賴執行時外部 CDN。

## 實作不可違反的規則

- 接資料庫與正式功能時，保留原型的導覽、資訊層級、版面、文字與操作位置，不得另做一套 UI。
- 原型未涵蓋的新功能先依既有設計語言補進原型／規格，確認後再實作。
- 技術限制若需要偏離，先記錄差異並取得確認，不可在實作中自行決定。
- 驗收要建立逐頁 parity checklist，並以手機與電腦截圖對照；功能測試通過不代表 UI 已通過。

更新介面時先修改 `family-finance-ui.source.html`，再產生 `family-finance-ui.html` 預覽，避免兩份內容漂移。
